# Super Mario · site

Site estático (HTML + JS puro), pronto para a Vercel. Não precisa de build nem de Node.

## Publicar
1. vercel.com → Add New → Project → envie esta pasta (ou suba num repositório GitHub e importe).
2. Framework Preset: **Other** · Build Command: vazio · Output Directory: `.`

## Fotos
As fotos em `img/` são ilustrativas (Unsplash). Troque pelas reais mantendo o mesmo nome.
- Cards e etapas: 800 px de largura, JPG ~80%.
- `hero.jpg` (1920 px) + `hero-960.jpg` (960 px) · `encomenda.jpg` (1600 px) + `encomenda-800.jpg` (800 px).
